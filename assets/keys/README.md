# Built-in AVB test keys

The user-provided `testkey_rsa2048.pem` and `testkey_rsa4096.pem` are public test private keys bundled with the application. They can be selected using `builtin:rsa2048` and `builtin:rsa4096`. Use a private key of your own for production signing.
